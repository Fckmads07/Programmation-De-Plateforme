## 🎯 À propos

Ce cours introduit la programmation de microcontrôleurs avec **MicroPython** sur une carte **ESP32**. On y apprend à contrôler des composants électroniques (LED, boutons, capteurs, écrans) à partir de code Python.

## 🛠️ Technologies et matériel

| Élément | Détail |
|---|---|
| Langage | Python / MicroPython |
| Microcontrôleur | ESP32 |
| Éditeur | Visual Studio Code |
| Extension | Pymakr (communication avec la carte) |
| Protocoles | GPIO, PWM, I2C |
